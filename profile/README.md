# gofairway

Open-source monitoring tooling for Stellar payment infrastructure.

## About

gofairway builds open-source monitoring and observability tooling for the Stellar ecosystem. Its focus is verifying payment-corridor execution quality, tracking corridor health over time, and alerting when payment paths become degraded or unusable at realistic economic trade sizes.

## Projects

| Project | Description | Status |
| ------- | ----------- | ------ |
| [fairway](https://github.com/gofairway/fairway) | Continuous Stellar payment-corridor health monitor measuring real trade execution, tracking health over time, and alerting on state changes. | Active development |
